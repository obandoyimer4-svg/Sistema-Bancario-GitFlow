# Evidencias de los comandos Git

## 1. Configuración de Git

### Comando

```bash
git config --list
```

### Evidencia

*(Aquí pegaré el pantallazo de la salida del comando.)*

### Descripción

Este comando permite visualizar toda la configuración actual de Git, incluyendo el nombre del usuario, correo electrónico, editor predeterminado y otras configuraciones del repositorio.

---

## 2. Estado del repositorio

### Comando

```bash
git status
```

### Evidencia

*(Aquí pegaré el pantallazo.)*

### Descripción

Muestra el estado actual del repositorio indicando los archivos modificados, agregados o pendientes por confirmar mediante un commit.

---

## 3. Historial de commits

### Comando

```bash
git log --oneline --graph --all
```

### Evidencia

*(Aquí pegaré el pantallazo.)*

### Descripción

Permite visualizar el historial de commits del proyecto de forma resumida y muestra gráficamente las ramas creadas durante el desarrollo.

---

## 4. Ramas del proyecto

### Comando

```bash
git branch -a
```

### Evidencia

*(Aquí pegaré el pantallazo.)*

### Descripción

Lista todas las ramas existentes en el repositorio, tanto locales como remotas.

---

## 5. Repositorio remoto

### Comando

```bash
git remote -v
```

### Evidencia

*(Aquí pegaré el pantallazo.)*

### Descripción

Permite visualizar el repositorio remoto configurado y las direcciones utilizadas para enviar y recibir cambios.

---

## Conclusión

Durante el desarrollo del proyecto se utilizaron los principales comandos de Git para gestionar el repositorio, controlar versiones, crear ramas, realizar commits, fusionar cambios y sincronizar el trabajo con GitHub. Estas evidencias demuestran el uso práctico de Git Flow y el trabajo colaborativo realizado durante la actividad.
